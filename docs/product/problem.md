# Problem Statement
- Modern software systems evolve continuously, but their documentation often does not evolve with them. Developers frequently modify code without updating the corresponding architecture, API, module, and functional documentation. Over time, this creates a growing gap between how the software actually works and how it is documented.

- Existing documentation tools often depend on developers manually writing or updating documentation, while generic AI coding tools typically generate documentation on demand without maintaining a persistent, structured understanding of the codebase.

## What exactly is the problem then?

- How can we automatically understand changes in a software codebase, determine which documentation is affected, and generate or update accurate, structured documentation while keeping developers in control of the final changes?
